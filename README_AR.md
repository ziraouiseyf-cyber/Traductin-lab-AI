# Candle Lab AI — Android learning simulator

هذه حزمة مشروع Android قابلة للبناء سحابياً من الهاتف عبر GitHub Actions.

## ما تحتويه النسخة 1.0.0
- تطبيق Android أصلي بغلاف WebView وواجهة عربية RTL.
- لوحة رئيسية ورسم شموع محلي.
- حسابات وصفية: RSI(14)، متوسط مدى الشموع، ومقارنة SMA10/SMA30.
- استيراد CSV بأعمدة `open,high,low,close` وعمود `time` اختياري.
- محفظة محاكاة افتراضية تبدأ بـ 10,000 دولار.
- سجل نتائج افتراضية، نسبة ربح، Profit Factor مبسط، وسلاسل الربح والخسارة.
- حفظ محلي للبيانات باستخدام LocalStorage.
- دروس تعليمية أساسية.

## ما لا تحتويه
- لا يوجد اتصال مباشر بأسعار حية أو بخادم MT5.
- تطبيق MT5 على Android لا يوفّر واجهة عامة مباشرة لتطبيقات الطرف الثالث لقراءة بياناته.
- لا يوجد تنفيذ أو إرسال أوامر تداول، ولا تكامل مع حساب وسيط.
- لا توجد خدمة ذكاء اصطناعي سحابية أو تحليل آلي متقدم لمدارس SMC/ICT/Wyckoff/Elliott؛ المعروض حالياً أدوات وصفية وتعليمية فقط.
- البيانات التي يولدها التطبيق تجريبية بحتة وليست أسعاراً حقيقية.
- حساب ربح/خسارة المحاكاة يستخدم معامل سعر × حجم تعليمي مبسط، ولا يطابق قيمة العقد أو النقطة لدى وسيطك.

## بناء APK من الهاتف
1. حمّل ZIP وفك ضغطه.
2. في GitHub أنشئ مستودعاً جديداً باسم `CandleLabAI`.
3. ارفع **محتويات** المجلد إلى جذر المستودع، بما فيها `.github`.
4. افتح تبويب Actions.
5. شغّل `Build Candle Lab AI APK` أو انتظر تشغيله بعد push إلى الفرع `main`.
6. بعد نجاح المهمة، افتح التشغيل ونزّل Artifact باسم `CandleLabAI-debug-apk`.
7. فك ضغط Artifact على الهاتف ثم ثبّت `app-debug.apk`.

## المتطلبات التقنية
- Android Gradle Plugin 8.5.2
- Gradle 8.7
- Java 17
- Android SDK Platform 35
- minSdk 23 (Android 6.0+)

## الخصوصية والسلامة
- لا تطلب الحزمة اسم مستخدم الوسيط أو كلمة مروره.
- البيانات وسجل المحاكاة يحفظان محلياً على الجهاز.
- لا ترفع بيانات حسابك أو مفاتيح API إلى GitHub.
- هذا برنامج تعليمي ومحاكاة، وليس نصيحة مالية أو نظام تداول.
